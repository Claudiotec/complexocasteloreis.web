PASSO 1: Descobrir o IP do seu computador
Abra o Prompt de Comando

Pressione Windows + R

Digite cmd e pressione Enter

Digite o comando:

cmd
ipconfig
Procure por "IPv4 Address" (geralmente no adaptador Wi-Fi ou Ethernet)

text
IPv4 Address. . . . . . . . . . . : 192.168.1.100
Anote esse IP! Você vai precisar dele.

🔧 PASSO 2: Configurar o Apache
Abra o arquivo de configuração do Apache:

text
C:\xampp\apache\conf\httpd.conf
Use o Bloco de Notas ou Notepad++ como Administrador

Encontre a linha:

apache
Listen 80
Substitua por:

apache
Listen 0.0.0.0:80
Encontre a linha:

apache
ServerName localhost:80
Substitua por (use o IP que você anotou):

apache
ServerName 192.168.1.100:80
Salve o arquivo (Ctrl+S)

Reinicie o Apache:

Abra o XAMPP Control Panel

Clique em Stop no Apache

Depois clique em Start novamente

🛡️ PASSO 3: Liberar a Porta no Firewall do Windows
Opção 1 - Usando o PowerShell (MAIS RÁPIDO)
Abra o PowerShell como Administrador:

Clique com o botão direito no Menu Iniciar

Escolha "Windows PowerShell (Admin)"

Digite este comando:

powershell
New-NetFirewallRule -DisplayName "Apache HTTP Server" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow
Pressione Enter

Opção 2 - Configuração Manual
Abra o Firewall:

Pressione Windows + R

Digite wf.msc e pressione Enter

Clique em "Regras de Entrada" no lado esquerdo

Clique em "Nova Regra..." no lado direito

Selecione "Porta" e clique em Avançar

Selecione "TCP" e "Portas locais específicas":

text
80
Selecione "Permitir a conexão"

Marque todas as opções:

☑ Domínio

☑ Privado

☑ Público

Dê um nome: Apache HTTP Server

Clique em Concluir

🔄 PASSO 4: Testar se o sistema está acessível
No seu computador:
Abra o navegador

Digite:

text
http://localhost/softgest_web/
ou

text
http://192.168.1.100/softgest_web/
Deve abrir o sistema normalmente!

📱 PASSO 5: Acessar de outro computador na rede
No computador do outro usuário:
Conecte-se à mesma rede Wi-Fi que o servidor

Abra o navegador (Chrome, Edge, Firefox)

Digite na barra de endereços:

text
http://192.168.1.100/softgest_web/
Substitua 192.168.1.100 pelo IP do servidor

Faça login normalmente

❓ PASSO 6: Criar um atalho para facilitar
No servidor, crie um arquivo MEU_IP.bat:
Abra o Bloco de Notas

Cole o código:

batch
@echo off
echo ========================================
echo SEU IP PARA ACESSO NA REDE
echo ========================================
echo.
for /f "tokens=2 delims=:" %%a in ('ipconfig ^| findstr "IPv4"') do (
    echo http:%%a/softgest_web/
)
echo.
echo Pressione qualquer tecla para copiar...
pause >nul
Salve como MEU_IP.bat (na área de trabalho)

Execute o arquivo para ver seu IP

⚠️ PASSO 10: Resolver Problemas Comuns
Problema: "Não consigo acessar"
Verifique:

O servidor está ligado?

O Apache está rodando? (XAMPP)

Os dois computadores estão na mesma rede?

O firewall está liberado?

Teste rápido:
cmd
ping 192.168.1.100
(Substitua pelo IP do servidor)

Se responder, a rede está OK.

Se não funcionar:
cmd
# Verificar porta 80
netstat -an | findstr :80

# Verificar firewall
netsh advfirewall show allprofiles
