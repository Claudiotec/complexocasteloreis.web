6. 📌 MÉTODO PHP - Criar um arquivo para ver o IP
Crie um arquivo chamado ver_ip.php na pasta softgest_web:

php
<?php
// ============================================
// ver_ip.php - Ver IP do Servidor
// ============================================

echo "<h1>🔍 Informações de IP</h1>";

// IP do servidor
echo "<h3>🖥️ IP do Servidor:</h3>";
echo "<pre>";
echo "SERVER_ADDR: " . ($_SERVER['SERVER_ADDR'] ?? 'Não disponível') . "\n";
echo "HTTP_HOST: " . ($_SERVER['HTTP_HOST'] ?? 'Não disponível') . "\n";
echo "REMOTE_ADDR: " . ($_SERVER['REMOTE_ADDR'] ?? 'Não disponível') . "\n";
echo "</pre>";

// IP via PHP
echo "<h3>📡 IP via PHP:</h3>";
echo "<pre>";
echo "gethostname(): " . gethostname() . "\n";
echo "gethostbyname(): " . gethostbyname(gethostname()) . "\n";
echo "</pre>";

// IP via comandos do sistema
echo "<h3>💻 IP via Comandos do Sistema:</h3>";
echo "<pre>";

if (PHP_OS_FAMILY === 'Windows') {
    $ip = shell_exec('ipconfig | findstr "IPv4"');
    echo $ip;
} else {
    $ip = shell_exec('hostname -I 2>/dev/null');
    echo $ip;
}

echo "</pre>";

// Função para detectar IP
function getLocalIP() {
    if (PHP_OS_FAMILY === 'Windows') {
        $ip = shell_exec('ipconfig | findstr "IPv4"');
        if (preg_match('/IPv4.*?(\d+\.\d+\.\d+\.\d+)/', $ip, $matches)) {
            return $matches[1];
        }
    } else {
        $ip = shell_exec('hostname -I 2>/dev/null');
        if ($ip) {
            $ips = explode(' ', trim($ip));
            return $ips[0] ?? null;
        }
    }
    return 'Não foi possível detectar';
}

echo "<h3>✅ IP Detectado:</h3>";
echo "<pre style='font-size:24px;color:#2ecc71;'>";
echo "IP: " . getLocalIP();
echo "</pre>";
?>
Acesse: http://localhost/softgest_web/ver_ip.php

7. 📌 MÉTODO NO NAVEGADOR - JavaScript
Crie um arquivo ip_browser.html:

html
<!DOCTYPE html>
<html>
<head>
    <title>Ver IP no Navegador</title>
</head>
<body>
    <h1>🌐 Seu IP</h1>
    <div id="ip" style="font-size:24px;color:blue;">Carregando...</div>
    
    <script>
        // Usando API pública
        fetch('https://api.ipify.org?format=json')
            .then(response => response.json())
            .then(data => {
                document.getElementById('ip').innerHTML = 'IP Público: ' + data.ip;
            })
            .catch(() => {
                document.getElementById('ip').innerHTML = 'Não foi possível obter IP público';
            });
    </script>
</body>
</html>
8. 📌 COMANDOS RÁPIDOS (Copiar e Colar)
Windows:
cmd
# Comando mais simples
ipconfig | findstr IPv4

# Comando formatado
for /f "tokens=2 delims=:" %a in ('ipconfig ^| findstr "IPv4"') do @echo IP: %a

# Mostrar apenas o IP (sem texto extra)
for /f "tokens=2 delims=:" %a in ('ipconfig ^| findstr "IPv4"') do @echo %a
Linux/Mac:
bash
# IP da interface principal
hostname -I | awk '{print $1}'

# IP da Wi-Fi
ip addr show wlan0 | grep inet | awk '{print $2}' | cut -d/ -f1

# IP da Ethernet
ip addr show eth0 | grep inet | awk '{print $2}' | cut -d/ -f1
9. 📌 VER IP EM REDES DIFERENTES
Ver IP da rede Wi-Fi:
cmd
ipconfig | findstr /i "wi-fi" -A 5
Ver IP da rede Ethernet (cabo):
cmd
ipconfig | findstr /i "ethernet" -A 5
Ver todas as interfaces:
cmd
ipconfig /all | findstr /i "ipv4"
